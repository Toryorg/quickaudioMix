# English
quickaudioMix
fast and light audiomixer for windows on python
## Requirements
- Windows 10/11
- Python 3.15 (python.org)
- Libraries: pycaw, psutil, comtypes, keyboard

## Installation
1. Install Python
2. Run `install.bat` (installs libraries)
3. Run `app_mixer.pyw`
4. for `install.bat`: `py -m pip install pycaw psutil comtypes keyboard`
